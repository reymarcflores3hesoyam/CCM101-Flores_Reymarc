**Lab 04: Cloud-Native Engineering**

**Overview**
This lab explores container technology and Docker fundamentals. Key tasks include contrasting virtual machines with containers, navigating the KillerCoda Docker interface, running an Nginx container, and controlling container lifecycles.

**Core Objectives**

* Compare VM architecture against containerization.
* Utilize a cloud-based Docker sandbox.
* Run essential Docker CLI operations.
* Launch and administer an Nginx web server container.
* Log all Docker workflows using Markdown.
