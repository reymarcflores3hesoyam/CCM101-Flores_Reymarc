### Reflection

Object Storage is better for storing millions of photos because it can handle a large amount of data and can easily grow as more photos are added. Unlike traditional storage, it is useful for storing photos and other unstructured files. This makes it a good choice for applications that need to store many images.

Docker made it easier to deploy MinIO because we could run the storage server using a single command. We did not need to manually install and configure many components. A bucket is a container used to store and organize files or objects. In this activity, we created a bucket called `client-photos` and uploaded a sample file.

Large companies protect their data through **Erasure Coding, Cross-Region and Multi-AZ Replication, and Versioning and Immutability**. These methods help recover data when drives or servers fail and protect files from accidental deletion or other problems. My confidence in using Linux is also improving because I am becoming more comfortable with Docker commands, ports, and environment variables. This activity helped me understand Object Storage and Docker better.
