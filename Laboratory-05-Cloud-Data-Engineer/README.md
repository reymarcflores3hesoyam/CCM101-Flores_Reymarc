# Laboratory 05: The Cloud Data Engineer

## Mission Overview

This laboratory focuses on cloud storage and Object Storage using MinIO and Docker. I compared Block, File, and Object Storage, deployed MinIO in a Docker container, and used the MinIO Web Console to create a bucket and upload a file.

## Objectives

- Compare Block, File, and Object Storage.
- Deploy MinIO using Docker.
- Access MinIO through the Web Console.
- Create a storage bucket and upload a file.
- Document the activity using Markdown.
- Add the laboratory to my GitHub portfolio.

## Tools Used

- **KillerCoda** – Ubuntu/Docker environment
- **Docker** – Container deployment
- **MinIO** – Object Storage server
- **GitHub** – Documentation and portfolio
- **Markdown** – Technical documentation

## Skills Learned

- Comparing different cloud storage types.
- Deploying MinIO using Docker.
- Using Docker environment variables and port mapping.
- Creating buckets and uploading objects.
- Managing cloud storage through a web console.
- Documenting cloud activities using Markdown.
