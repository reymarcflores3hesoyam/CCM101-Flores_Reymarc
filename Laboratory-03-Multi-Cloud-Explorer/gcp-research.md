
# Google Cloud Platform (GCP)

## Brief Overview

Google Cloud Platform (GCP) is Google's cloud computing platform. It provides services for computing, storage, networking, databases, artificial intelligence, machine learning, analytics, and application development.

## Global Infrastructure

Google Cloud uses a global infrastructure organized into regions and zones. Organizations can deploy resources in specific regions and zones or use services that operate across multiple regions. This infrastructure helps support global applications and workloads.

## Cloud Management Console

Google Cloud Console is a web-based interface used to manage Google Cloud resources and services. It allows users to create, configure, monitor, and manage cloud resources.

## Four Core Services

### 1. Compute Engine

Compute Engine provides virtual machines that run on Google's cloud infrastructure.

### 2. Cloud Storage

Cloud Storage is an object storage service used to store and retrieve data in the cloud.

### 3. Google Virtual Private Cloud (VPC)

Google Cloud VPC provides networking functionality for virtual machines, containers, and other cloud workloads.

### 4. Google Kubernetes Engine (GKE)

Google Kubernetes Engine is a managed environment for deploying and managing containerized applications using Kubernetes.

## Three Advantages

1. Google Cloud has strong capabilities for artificial intelligence and machine learning.
2. Google Cloud provides strong data analytics and processing services.
3. Google Cloud has strong Kubernetes and container technology capabilities.

## Typical Enterprise Use Cases

- Artificial intelligence and machine learning
- Big data and analytics
- Web applications
- Containerized applications
- Kubernetes deployments
