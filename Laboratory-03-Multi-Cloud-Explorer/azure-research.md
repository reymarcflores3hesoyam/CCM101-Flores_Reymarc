# Microsoft Azure

## Brief Overview

Microsoft Azure is Microsoft's cloud computing platform. It provides services for computing, storage, networking, databases, security, AI, and application development.

## Global Infrastructure

Azure has regions, datacenters, and availability zones around the world. These help users run their applications and store their data in different locations.

## Cloud Management Console

The Azure Portal is a website used to manage Azure services. Users can create, manage, and monitor their cloud resources using the portal.

## Four Core Services

### 1. Azure Virtual Machines

Azure Virtual Machines provide virtual computers that can be used to run applications and operating systems.

### 2. Azure Blob Storage

Azure Blob Storage is used to store files and data such as documents, images, videos, and backups.

### 3. Azure Virtual Network

Azure Virtual Network provides a private network for Azure resources. It allows resources to communicate with each other.

### 4. Microsoft Entra ID

Microsoft Entra ID is used to manage users and access to Azure resources. It helps control who can access different services.

## Three Advantages

1. Azure works well with Microsoft products.
2. Azure has services available in many locations around the world.
3. Azure provides many services for businesses and organizations.

## Typical Enterprise Use Cases

- Windows Server
- Microsoft applications
- Cloud databases
- Business applications
- Hybrid cloud
