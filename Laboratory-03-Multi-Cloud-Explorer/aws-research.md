
# Amazon Web Services (AWS)

## Brief Overview

Amazon Web Services (AWS) is Amazon's cloud computing platform. It provides cloud services such as computing, storage, networking, databases, security, and application development. Organizations can use these services without having to maintain all of their own physical infrastructure.

## Global Infrastructure

AWS operates its cloud infrastructure through geographic Regions and Availability Zones. Each Region is a separate geographic area, while Availability Zones are isolated locations within a Region. This design helps organizations build applications with better availability, fault tolerance, and performance.

## Cloud Management Console

The AWS Management Console is a web-based interface used to access and manage AWS services and resources. Users can create, configure, monitor, and manage cloud resources through the console.

## Four Core Services

### 1. Amazon EC2

Amazon Elastic Compute Cloud (EC2) provides virtual servers that organizations can use to run applications and workloads.

### 2. Amazon S3

Amazon Simple Storage Service (S3) is an object storage service used to store and retrieve data such as files, backups, images, and application data.

### 3. Amazon VPC

Amazon Virtual Private Cloud (VPC) provides networking capabilities that allow organizations to create isolated networks for their cloud resources.

### 4. AWS IAM

AWS Identity and Access Management (IAM) controls access to AWS resources by managing users, roles, permissions, and policies.

## Three Advantages

1. AWS provides a wide range of cloud services for different business and technical requirements.
2. Its global infrastructure allows organizations to deploy applications in different geographic locations.
3. AWS services can scale according to changing workloads and business needs.

## Typical Enterprise Use Cases

- Hosting websites and web applications
- Data storage and backup
- Enterprise application hosting
- Disaster recovery
- Data processing and analytics
