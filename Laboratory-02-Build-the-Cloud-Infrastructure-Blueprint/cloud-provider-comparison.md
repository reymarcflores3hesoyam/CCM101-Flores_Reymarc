# Cloud Provider Comparison

| Infrastructure Service | Amazon Web Services (AWS) | Microsoft Azure | Google Cloud Platform (GCP) |
|-------------------------|---------------------------|-----------------|-----------------------------|
| Compute | Amazon EC2 | Azure Virtual Machines | Compute Engine |
| Storage | Amazon S3 | Azure Blob Storage | Cloud Storage |
| Networking | Amazon VPC | Azure Virtual Network | VPC Network |
| Identity and Access Management | AWS IAM | Microsoft Entra ID (Azure AD) | Cloud IAM |

---

## Guide Questions

### 1. Which cloud provider appears to offer the broadest range of infrastructure services?

Amazon Web Services (AWS) offers the broadest range of infrastructure services because it provides many solutions for computing, storage, networking, databases, security, and artificial intelligence.

### 2. Which provider would be most suitable for organizations heavily invested in Microsoft technologies?

Microsoft Azure is the best choice for organizations using Microsoft technologies because it integrates well with Windows Server, Microsoft 365, and Microsoft Entra ID (formerly Azure Active Directory).

### 3. Which provider seems strongest in artificial intelligence and machine learning services?

Google Cloud Platform (GCP) is well known for its artificial intelligence and machine learning services. It also provides powerful tools for data analytics and Kubernetes.

### 4. What similarities do you observe across all three cloud providers?

All three providers offer compute, storage, networking, and identity management services. They also provide secure, scalable, and reliable cloud infrastructure for businesses.
