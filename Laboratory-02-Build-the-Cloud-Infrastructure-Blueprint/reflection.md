# Reflection

Among the cloud infrastructure components, I believe that compute resources are the most important because they provide the processing power needed to run applications and services. Without compute resources, cloud systems would not be able to perform tasks or process user requests. Storage and networking are also important, but compute resources are the foundation that allows applications to function.

Linux plays a major role in cloud computing because it is stable, secure, and efficient. Many cloud providers use Linux as the operating system for their servers because it can handle multiple tasks, supports automation, and works well with cloud technologies. Learning basic Linux commands helped me understand how cloud servers are managed and monitored.

Technical documentation is important before deploying infrastructure because it helps engineers understand the system design, configuration, and resources being used. It also reduces mistakes during deployment and makes it easier for team members to collaborate, troubleshoot problems, and maintain the infrastructure in the future.

During this laboratory activity, I learned how to organize a GitHub repository, write technical documentation using Markdown, compare major cloud providers, and identify the different components of cloud infrastructure. I also became familiar with the purpose of compute, storage, networking, and operating system resources.

After completing this mission, my GitHub portfolio became more organized and professional. It now contains structured documentation, comparison tables, and diagrams that demonstrate my understanding of cloud infrastructure. This activity also improved my confidence in using GitHub and preparing technical documents that can be useful in future cloud computing projects.
