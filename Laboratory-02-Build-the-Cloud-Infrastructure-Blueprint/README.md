# Laboratory 02 – Build the Cloud Infrastructure Blueprint

## Mission Overview
This laboratory activity focuses on understanding the basic components of cloud infrastructure. The goal is to investigate a Linux cloud server, identify cloud infrastructure resources, compare major cloud providers, and create a simple cloud architecture diagram.

---

## Objectives
- Explain the major components of cloud infrastructure.
- Identify compute, storage, networking, and operating system resources.
- Compare AWS, Microsoft Azure, and Google Cloud Platform services.
- Create a simple cloud infrastructure diagram.
- Improve technical documentation skills using Markdown.

---

## Cloud Infrastructure Components
- **Compute** – Provides processing power to run applications.
- **Storage** – Stores files, databases, and application data.
- **Networking** – Connects cloud resources and users through the internet.
- **Operating System** – Manages hardware and software resources.
